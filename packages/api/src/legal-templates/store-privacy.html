2. Состав персональных данных и цели обработки

2.1. Продавец собирает и обрабатывает следующие персональные данные Покупателя:

2.1.3. Идентификатор заказа и дата оплаты — для исполнения обязательств по договору купли-продажи;

2.1.4. Адрес электронной почты (при его указании Покупателем) — для обратной связи.

2.2. Обработка персональных данных осуществляется в целях исполнения договора купли-продажи цифровых товаров, а также для предотвращения мошеннических действий.

3.1. Обработка персональных данных осуществляется на основании:

4. Сроки обработки и хранения персональных данных

4.1. Персональные данные Покупателя хранятся в течение срока, необходимого для исполнения договора купли-продажи, и удаляются не позднее 3 (трёх) лет после завершения взаиморасчётов.

4.2. Хешированные IP-адреса хранятся не более 90 (девяноста) дней.

4.3. По истечении указанных сроков персональные данные уничтожаются автоматически.
